# 🎌 Anime Studio – AI-Powered Anime Comic Generation Platform

Anime Studio is a Generative AI-powered web application that transforms user prompts into engaging anime-style comics. Using the Google Gemini API, the application generates complete comic stories with character descriptions, dialogues, and scene-wise comic panels, providing users with an interactive comic creation experience.

---

## 🚀 Features

- Generate anime-style comic stories from user prompts.
- AI-powered story, dialogue, and character description generation using Google Gemini.
- Multiple comic genres:
  - Action
  - Romance
  - Fantasy
  - Adventure
  - Sci-Fi
- Comic-style speech bubbles for dialogues.
- Story consistency across multiple comic panels.
- Hover-to-hear dialogue playback.
- Voice options:
  - Male
  - Female
  - No Voice
- Download generated comics.
- Responsive and user-friendly interface.

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/akankshagurdhani17-collab/animeStudio
```

### Navigate to the project folder

```bash
cd Anime-Studio
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Add your Google Gemini API Key

Create a `.env` file and add:

```text
GEMINI_API_KEY=your_api_key_here
```

### Run the application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
